# not-jira <img src="not-jira.webp" height="40" align="right" alt="not-jira logo" />

Telegram-бот для трекинга багов и идей в форумах. Задачи собираются из топиков, а управление ими происходит в личных сообщениях с ботом.

## Функционал

- **Создание задач из топиков:** ответ командой `/add` на сообщение пользователя создает задачу с префиксом `B` (баги) или `I` (идеи) и ссылкой на исходный пост.
- **AI-суммаризация:** автоматическое выделение заголовка и сути через OpenAI-совместимый API (OpenRouter, Groq, Mistral или локальная Ollama). Если AI выключен или недоступен, первой строкой становится заголовок.
- **Ролевая модель:**
  - Администраторы (`admin_ids`): полный доступ ко всем задачам, передача задач, ручная архивация, команда `/backup`.
  - Разработчики (`dev_ids`): возможность брать задачи себе (`[👤 Взять себе]`), управлять назначенными на себя задачами и передавать их.
  - Пользователи: могут предлагать задачи через топики и принимать переданные задачи.
- **Доступ по членству в форуме:** если задан `forum_chat_id`, команды в ЛС доступны только участникам форума (админы и разработчики — всегда). Для неучастников можно указать `forum_url` со ссылкой-приглашением.
- **Передача задач:** отправка тикета другому пользователю через ЛС с кнопками подтверждения или отказа.
- **Приоритеты и теги:** 4 уровня приоритета (`Блокер`, `Высокий`, `Обычный`, `Низкий`), готовые теги из конфига и фильтрация в `/list`.
- **Подзадачи и комментарии:** чекбоксы с зачеркиванием текста, визуальный прогресс-бар и ветка комментариев.
- **История изменений:** кнопка «История» в карточке задачи показывает цепочку событий (создание, статус, приоритет, исполнитель, правки, архивация) с автором и временем.
- **Живучесть форм:** незаконченные формы в ЛС (создание/редактирование) сохраняются в SQLite и переживают перезапуск бота.

## Команды

| Команда | Где вызывается | Доступ | Описание |
|---|---|---|---|
| `/add` | В топике форума (реплаем) | Админы, разработчики | Создать задачу из сообщения |
| `/list` | В ЛС с ботом | Участники форума | Список задач с фильтрами |
| `/my` | В ЛС с ботом | Участники форума | Задачи пользователя («На мне» / «Созданные мной») |
| `/view <ID>` | В ЛС с ботом | Участники форума | Карточка задачи |
| `/backup` | В ЛС с ботом | Админы | Скачать дамп базы SQLite |
| `/settings` | В ЛС с ботом | Участники форума | Настройки уведомлений (вкл/выкл ЛС, со звуком/без звука в топиках форума) |

## Установка и запуск

### Сборка

```bash
git clone https://github.com/nonFeature/not-jira.git
cd not-jira
go build -o bin/not-jira ./cmd/bot
```
да, вам нужен [go](https://go.dev/), гоферу привет передайте

### Релизы

Бинарники под Linux (amd64) собираются вручную: **Actions → Release → Run workflow**, укажите тег (например `v1.0.0`) — workflow соберёт бинарник и создаст GitHub Release. Тег подставляется в бинарник через `-X main.version`.

### Конфигурация (`config.yaml`)

ну вы неглупенькие, у вас есть [пример конфига](config.example.yaml), так что копируйте и редактируйте

### Запуск

```bash
./bin/not-jira
```
