# not-jira

> **Jira, но не Jira.**  
> Легковесный трекер багов и идей для Telegram-сообществ и разработчиков, работающий прямо поверх топиков форума.

---

## 🎯 Суть проекта

В Telegram-сообществах (например, [@nonForum](https://t.me/nonForum)) пользователи постоянно пишут о багах, делятся идеями и предложениями. Обычно эти сообщения теряются во флуде, а разворачивать тяжелые системы вроде Jira или Redmine ради пет-проектов — избыточно.

**not-jira** решает эту проблему:
* Он превращает обычные сообщения из топиков форума в упорядоченные задачи для разработчика.
* Не засоряет публичные чаты: все карточки, кнопки управления, редактирование и формы живут **строго в личных сообщениях с ботом**.
* В публичном топике бот оставляет только короткие отметки: подтверждение о приеме и уведомление, когда баг исправлен или фича сделана.
* Потребляет минимум ресурсов (буквально 10–15 МБ оперативной памяти) и может работать где угодно — от домашнего роутера или микро-сервера до обычного ПК.

## ⚡️ Функционал

### 1. Сбор задач из топиков форума
* **Единая команда `/add`:** админ отвечает командой на сообщение пользователя в соответствующем топике форума.
* **Умная категоризация и ID:**
  * Сообщения из топика багов получают префикс **`B0`**, **`B1`**, **`B2`**...
  * Сообщения из топика идей получают префикс **`I0`**, **`I1`**, **`I2`**...
* **Привязка к источнику:** бот сохраняет автора и кликабельную ссылку на оригинальное сообщение в топике.
* **Чистый чат:** в топик уходит только короткое подтверждение (`✅ Ваш баг [B0] принят в обработку!`), а панель управления задачей прилетает админу в ЛС.

### 2. AI-суммаризация («Впитывание»)
* **Авто-обработка через нейросеть:** бот вычищает из длинного сообщения воду, эмоции и оффтоп, формируя лаконичный заголовок (до 60 символов) и техническую суть проблемы/предложения (1–3 предложения).
* **Поддержка любых моделей:** работает с Mistral AI, Groq, DeepSeek или любым другим OpenAI-совместимым API.
* **Ручной режим:** если нейросеть выключена, бот присылает админу в ЛС удобную пошаговую форму для ввода заголовка и описания вручную.

### 3. Управление задачами в стиле GitHub Issues
* **Интерактивный список (`/list`):**
  * Постраничная навигация (`⬅️ [Стр. 1/3] ➡️`).
  * Фильтрация по типам (`Все`, `🐛 Баги`, `💡 Идеи`) и статусам (`🆕 Новые`, `⚙️ В работе`, `✅ Готово`).
* **Детальная карточка (`/view <ID>`):**
  * Текст и форматирование цитатами Bot API 7.x/8.x.
  * **Подзадачи (саб-таски):** список чекбоксов (`☑️` / `⬜️`), переключаемых в один клик.
  * **Комментарии:** добавление заметок и логов разработчика к задаче.
  * **Редактирование:** изменение заголовка и описания в любой момент прямо из карточки.
  * **Жизненный цикл:** мгновенная смена статусов кнопками `[⚙️ В работу]`, `[✅ Готово]`, `[❌ Отклонить]`.

### 4. Оповещения («Получать уведы, что всё гуд»)
* При переходе задачи в статус **Готово** (`DONE`) или **Отклонено** (`REJECTED`):
  * Бот отправляет реплай на исходное сообщение автора в топике форума.
  * Автор получает персональное уведомление в ЛС (если запускал бота).
* Пользователь может в любой момент выключить личные уведомления через `/settings`.

### 5. Автономность и безопасность
* Встроенная база данных **SQLite** (`bot.db`) — никаких внешних СУБД, статический бинарник без CGO.
* Поддержка **SOCKS5-прокси** для стабильного подключения к Telegram API в любых сетевых условиях.
* Защита от спама: если пользователь вызывает команду в группе, бот отправляет ответ ему в ЛС, либо вежливо предлагает открыть с ним диалог по кнопке.
